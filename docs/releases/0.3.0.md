# Intake 0.3.0

This GitHub source release adds an all-items inbox view, mailbox source filtering, and a refined dashboard with progressive disclosure of secondary controls. It requires patched Node.js 22.23.4+, 24.22.1+, or 26.12.1+ on supported release lines.

Install the tagged checkout with `npm ci` and `npm link`. Existing local state stays in place; back it up before upgrading. The storage schema is unchanged. This package is not published to npm or Kennel.

Verification includes the full release gate, browser acceptance, and a clean installation from the published archive. Local operator and external-provider limitations remain unchanged.
